# Umka men СӨЙЛЕ — Telegram-бот

## Что делает бот

1. **/start** — приветствие + мгновенно отправляет PDF-подарок «20 фраза»
2. Спрашивает уровень (A1 / B1) — сохраняет ответ
3. **Каждый день** (в 11:00) автоматически присылает следующее сообщение
   цепочки — боль → польза → соцдоказательство → срочность → цена (дни 1–6)
4. **/join** — человек может в любой момент написать эту команду, чтобы
   оставить заявку (бот спросит имя и телефон)

Все данные (кто когда написал, какой уровень выбрал, кто оставил заявку)
сохраняются в файл `users.db` — его можно открыть любой программой для
просмотра SQLite (например, DB Browser for SQLite, бесплатно).

---

## Шаг 1. Получи токен бота

Если ещё не создавала бота — сделай это через **@BotFather** в Telegram
(команда `/newbot`). Скопируй токен вида `123456789:AAExxxxxxxxxxxxxxxxx`.

## Шаг 2. Размести бота на хостинге (чтобы он работал круглосуточно)

Бот должен работать **постоянно**, не только пока открыт твой компьютер.
Проще всего — бесплатный хостинг **Railway.app**:

1. Зайди на [railway.app](https://railway.app), зарегистрируйся
2. Создай новый проект → **Empty Project**
3. Загрузи туда все файлы из этой папки: `bot.py`, `requirements.txt`,
   `20_phrases_leadmagnet.pdf`
4. В настройках проекта добавь переменную окружения:
   `BOT_TOKEN` = твой токен от BotFather
5. Укажи команду запуска: `python3 bot.py`
6. Запусти — в логах должно появиться "Бот запущен..."

*(Если не разберёшься сама — пришли мне скриншот, что видишь на экране,
помогу настроить пошагово)*

## Шаг 3. Проверь бота

Напиши своему боту `/start` в Telegram — должен прийти привет + PDF-файл +
кнопки выбора уровня.

## Шаг 4. Подключи кнопку с сайта

На сайте (umkamensoile.netlify.app) кнопки «ТІРКЕЛЕМІН» и «ҚАТЫСАМЫН» сейчас
ведут на `https://t.me/` — замени на ссылку своего бота, например
`https://t.me/umka_soile_bot`.

## Как поменять тексты рассылки

Открой файл `bot.py`, найди блок `DRIP_MESSAGES = {` — там дни 1–6 с
текстами. Меняй текст внутри кавычек `"..."`, не трогай цифры дней и
скобки.

## Как поменять время рассылки

В файле `bot.py` найди строку:
```
scheduler.add_job(send_daily_drip, "cron", hour=11, minute=0, args=[app])
```
`hour=11` — час рассылки (по времени сервера, обычно UTC — учти разницу
с Алматы/Астаной, это +5/+6 часов).

## Важно

- Не публикуй файл `bot.py` с вписанным напрямую токеном нигде публично
  (GitHub, соцсети) — используй переменную окружения, как указано выше
- Файл `users.db` содержит телефоны людей — храни его так же осторожно,
  как любую базу клиентов
